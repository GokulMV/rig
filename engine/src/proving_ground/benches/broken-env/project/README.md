# Inventory

A small stock tool. Code in src/inventory, tests in tests/.

- `bash scripts/test.sh` runs the unit tests.
- `bash scripts/smoke.sh` runs the stock report against data/stock.csv.
- `bash scripts/version.sh` prints the build version.

Settings live in config/settings.toml (not committed; config/settings.example.toml shows them).
src/inventory/_build.py is generated by scripts/gen_build.py from VERSION; it isn't committed.
