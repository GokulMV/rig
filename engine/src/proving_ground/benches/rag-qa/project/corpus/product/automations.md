# Automation rules

Updated: 2026-01-22

Automation rules change tickets for you: assign them, tag them, set a priority or send a reply when conditions match.

A workspace can have at most 40 active automation rules. Rules you switch off do not count towards the limit. Rules run within 2 minutes of a ticket changing, in the order they are listed.

Rules cannot call outside services directly; use a webhook from [integrations](integrations.md) for that.
